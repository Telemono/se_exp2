以下为课程作业级概要设计，均以表格给出。设计约束：单文件 Python、命令行交互、标准库优先、本地 JSON 持久化、不使用 Web 框架、不使用数据库。

## 1 模块划分与职责

| 编号 | 模块 | 主要职责 | 关键函数/数据 | 输入 | 输出 |
|---|---|---|---|---|---|
| M1 | 程序入口与主控 | 启动系统、加载数据、登录、按角色进入菜单 | `main()` | 无 | 进入对应角色菜单 |
| M2 | 认证与权限 | 校验用户名密码、识别角色、控制菜单权限 | `login()`、`find_user()` | 用户名、密码 | 用户对象或登录失败 |
| M3 | 数据持久化 | 从 JSON 加载数据、保存数据、提供默认数据 | `load_data()`、`save_data()`、`DEFAULT_DATA`、`DATA_FILE` | 内存 `data` | JSON 文件 |
| M4 | 学生管理 | 查看学生、添加学生、查找学生 | `list_students()`、`add_student()`、`find_student()` | 学号、姓名、班级 | 学生列表/新增结果 |
| M5 | 课程管理 | 查看课程、添加课程、查找课程 | `list_courses()`、`add_course()`、`find_course()` | 课程号、课程名 | 课程列表/新增结果 |
| M6 | 成绩管理 | 录入、修改、查看成绩，按学生查询成绩 | `set_score()`、`list_scores()`、`query_student_scores()` | 学号、课程号、成绩 | 成绩记录/查询结果 |
| M7 | 统计模块 | 按课程统计人数、平均分、最高分、最低分 | `course_stats()` | 课程号 | 统计数据 |
| M8 | 学生自助查询 | 学生查看本人成绩和平均分 | `student_view_self()` | 当前登录用户 | 本人成绩 |
| M9 | 菜单交互 | 展示管理员、教师、学生菜单，接收选择 | `admin_menu()`、`teacher_menu()`、`student_menu()` | 菜单选项 | 调用对应业务函数 |
| M10 | 输入校验与工具 | 校验成绩范围、非空、数字格式；通用查找 | `input_score()`、`find_*()` | 用户输入 | 合法值或错误提示 |

## 2 模块调用关系

| 序号 | 调用方 | 被调用方 | 调用说明 |
|---|---|---|---|
| 1 | `main()` | `load_data()` | 启动时加载 JSON 数据 |
| 2 | `main()` | `login()` | 登录认证 |
| 3 | `login()` | `find_user()` | 按用户名查找用户 |
| 4 | `main()` | `admin_menu()` / `teacher_menu()` / `student_menu()` | 按角色进入菜单 |
| 5 | `admin_menu()` | 学生、课程、成绩、统计相关函数 | 管理员拥有全部管理功能 |
| 6 | `teacher_menu()` | `list_students()`、`list_courses()`、`set_score()`、`query_student_scores()`、`course_stats()` | 教师查看与成绩管理 |
| 7 | `student_menu()` | `student_view_self()` | 学生仅查看本人成绩 |
| 8 | `add_student()` | `find_student()`、`save_data()` | 查重后保存 |
| 9 | `add_course()` | `find_course()`、`save_data()` | 查重后保存 |
| 10 | `set_score()` | `find_student()`、`find_course()`、`input_score()`、`save_data()` | 校验学生、课程、成绩后保存 |
| 11 | `query_student_scores()` | `find_student()`、`find_course()` | 查询学生成绩并显示课程名 |
| 12 | `course_stats()` | `find_course()` | 查询课程后统计成绩 |
| 13 | `student_view_self()` | `find_student()`、`find_course()` | 根据登录用户绑定学号查成绩 |
| 14 | 各增删改函数 | `save_data()` | 数据变更后持久化 |

调用层次可概括为：  
`main → 认证/菜单 → 业务模块 → 查找/校验工具 → 持久化模块`

## 3 数据存储方式

| 设计项 | 内容 |
|---|---|
| 存储介质 | 本地 JSON 文件，默认文件名 `grades_data.json` |
| 是否使用数据库 | 否，不使用 SQLite、MySQL、MongoDB 等 |
| 内存模型 | 一个字典 `data`，包含 `users`、`students`、`courses`、`scores` |
| 用户数据 | `users`: `username`、`password`、`role`、`student_id` |
| 学生数据 | `students`: `id`、`name`、`class_name` |
| 课程数据 | `courses`: `id`、`name` |
| 成绩数据 | `scores`: `student_id`、`course_id`、`score` |
| 加载时机 | 程序启动时 `load_data()` |
| 保存时机 | 添加学生、添加课程、录入/修改成绩后 `save_data()` |
| 默认数据 | 文件不存在时写入 `DEFAULT_DATA` 并返回默认数据 |
| 数据约束 | 学号唯一、课程号唯一、成绩 0~100 |
| 并发能力 | 不支持多进程/多用户并发写入 |
| 容错策略 | JSON 损坏时提示并使用默认数据；IO 异常捕获后提示 |

## 4 异常处理策略

| 异常/边界场景 | 处理策略 | 涉及模块 |
|---|---|---|
| 学号为空 | 提示“学号不能为空”，不继续 | 学生管理 |
| 课程号为空 | 提示“课程号不能为空”，不继续 | 课程管理 |
| 姓名为空 | 提示“姓名不能为空”，不继续 | 学生管理 |
| 课程名为空 | 提示“课程名不能为空”，不继续 | 课程管理 |
| 学号重复 | 提示“学号已存在”，拒绝添加 | 学生管理 |
| 课程号重复 | 提示“课程号已存在”，拒绝添加 | 课程管理 |
| 成绩为空 | 提示成绩不能为空，重新输入 | 输入校验 |
| 成绩非数字 | 提示必须是数字，重新输入 | 输入校验 |
| 成绩越界 | 提示必须在 0~100，重新输入 | 输入校验 |
| 学生不存在 | 提示“学生不存在” | 成绩管理、查询 |
| 课程不存在 | 提示“课程不存在” | 成绩管理、统计 |
| 某课程无成绩 | 提示暂无成绩，不计算平均分，避免除零 | 统计模块 |
| 登录失败 | 最多尝试 3 次，失败后退出 | 认证模块 |
| 学生账号未绑定学号 | 提示“未绑定有效学号” | 学生自助查询 |
| 菜单无效选项 | 提示“无效选项”，重新选择 | 菜单交互 |
| JSON 文件不存在 | 自动创建默认数据文件 | 数据持久化 |
| JSON 文件损坏 | 捕获 `JSONDecodeError`，提示并使用默认数据 | 数据持久化 |
| 文件读写失败 | 捕获 `OSError`，提示保存/读取失败 | 数据持久化 |

## 5 不做哪些功能

| 序号 | 不做功能 | 原因/说明 |
|---|---|---|
| 1 | Web 界面与 Web 框架 | 明确要求不用 Flask、Django、FastAPI 等 |
| 2 | 数据库 | 明确要求不用数据库，改用 JSON 文件 |
| 3 | 多用户并发与网络访问 | 课程作业级单机 CLI，暂不考虑并发一致性 |
| 4 | 复杂权限系统 | 仅管理员、教师、学生三种简单角色 |
| 5 | 密码哈希与加密 | 演示版明文存储，生产环境需改造 |
| 6 | 删除学生/课程及级联删除 | 会涉及关联成绩清理，当前不实现 |
| 7 | 分页、排序、模糊搜索 | 小规模数据线性遍历即可 |
| 8 | Excel/CSV 导入导出 | 超出当前需求范围 |
| 9 | 图形界面 GUI | 仅命令行交互 |
| 10 | 事务、回滚、审计日志 | 课程作业级不要求 |
| 11 | 自动备份与恢复 | 不实现 |
| 12 | GPA、学分、加权成绩 | 仅实现平均分和课程统计 |
| 13 | 排课、考勤、教师管理 | 不属于学生成绩管理核心范围 |
| 14 | 单元测试与 CI | 可后续扩展，当前概要设计不包含 |
