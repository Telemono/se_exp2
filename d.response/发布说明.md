# 学生成绩管理系统 发布说明

## 1 版本信息

| 项 | 内容 |
|---|---|
| 产品名称 | 学生成绩管理系统（Student Grade Management System） |
| 版本号 | v1.1.0 |
| 发布日期 | 2026-10-05 |
| 交付形态 | 单文件 Python 脚本 `src/student_grade_system.py` |
| 运行方式 | 命令行交互（CLI） |
| 技术约束 | 仅标准库、无 Web 框架、无数据库、本地 JSON 持久化 |
| 源码规模 | 371 行 |

## 2 概述

本系统面向教学演示与软件工程课程实验，提供学生、课程与成绩的录入、查询和统计功能，采用菜单式命令行交互，数据以 JSON 文件保存在本地，无需安装任何第三方依赖。系统按角色（管理员 / 教师 / 学生）划分功能权限。

## 3 运行环境

| 项 | 要求 |
|---|---|
| Python | Python 3（开发与验证环境 3.10.11） |
| 操作系统 | Windows / Linux / macOS（不使用平台特有 API） |
| 第三方依赖 | 无，仅使用标准库 `json`、`os`、`statistics` |
| 终端 | 支持标准输入输出的命令行终端 |
| 编码 | 源码与数据文件均为 UTF-8 |

## 4 安装与启动

1. 确认已安装 Python 3：`python --version`
2. 进入源码目录并运行：

```bash
python src/student_grade_system.py
```

3. 首次运行会在**当前工作目录**自动生成 `grades_data.json` 并写入内置默认数据。
4. 按屏幕提示登录，输入用户名与密码（连续错误 3 次程序退出）。

> 注意：数据文件路径为进程当前工作目录下的 `grades_data.json`。若在不同目录启动，会各自生成独立数据文件。建议在固定目录运行。

## 6 功能清单

### 6.1 登录与鉴权
- 用户名 + 密码登录，连续失败 3 次退出。
- 按角色进入对应菜单。

### 6.2 管理员
- 查看 / 添加学生（学号唯一，姓名非空，性别/班级可空）
- 查看 / 添加课程（课程号唯一，课程名非空）
- 查看全部成绩
- 录入 / 修改成绩
- 查询指定学生成绩与平均分
- 课程统计（人数、平均分、最高分、最低分）

### 6.3 教师
- 查看学生、查看课程
- 录入 / 修改成绩
- 查询学生成绩
- 课程统计

### 6.4 学生
- 查看本人各科成绩与平均分（仅限本人数据）

### 6.5 数据持久化
- 启动时从 `grades_data.json` 加载；不存在时创建默认数据。
- 新增学生、新增课程、录入/修改成绩后立即写回文件。
- 文件损坏时提示并回退默认数据（不覆盖原文件，但后续保存会覆盖）。

## 7 数据文件说明

| 项 | 说明 |
|---|---|
| 文件名 | `grades_data.json` |
| 位置 | 程序运行的当前工作目录 |
| 顶层结构 | `users` / `students` / `courses` / `scores` 四个数组 |
| 备份 | 复制该文件即可备份；删除该文件后重启可恢复默认数据 |
| 编码 | UTF-8，`ensure_ascii=False`，缩进 2 |

## 9 已知问题与限制

| 编号 | 级别 | 说明 |

| D01 | 一般 | 学生菜单选项 1「查看我的成绩」与选项 2「查看我的平均分」输出完全相同，无法只显示平均分 |
| D02 | 一般 | 数据保存失败时仅打印错误，不回滚内存、不给出明确失败提示，存在内存与磁盘不一致窗口 |

| D04 | 轻微 | 不提供删除学生/课程/成绩功能，无级联清理 |
